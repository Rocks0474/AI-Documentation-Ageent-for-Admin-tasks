# AI Documentation Agent for Admin Tasks

An AI-powered assistant for generating and maintaining documentation for administrative workflows.

## Getting Started with Claude Code

This project is designed to be developed with [Claude Code](https://docs.claude.com/en/docs/claude-code/overview), Anthropic's official CLI for Claude.

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm (bundled with Node.js)
- An Anthropic account with access to Claude Code

### Install the Claude Code CLI

```bash
npm install -g @anthropic-ai/claude-code
```

### Run Claude Code on this project

```bash
cd path/to/AI-Documentation-Ageent-for-Admin-tasks
claude
```

On first launch, Claude Code will prompt you to authenticate. Follow the on-screen instructions to sign in.

### Other ways to use Claude Code

In addition to the local CLI, you can use Claude Code from:

- The desktop app (macOS and Windows)
- The web app at [claude.ai/code](https://claude.ai/code)
- IDE extensions for VS Code and JetBrains

See the [Claude Code documentation](https://docs.claude.com/en/docs/claude-code/overview) for details.
